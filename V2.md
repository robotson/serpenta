# Serpenta V2

V2 lives beside the original 2018 build and does not replace it.

## Rules

- The logical board is fixed at 18 × 11 cells.
- Direction input is a single replaceable steering intent, committed at the next cell boundary.
- Each level asks for a larger certified minimum body length.
- A layout is certified only when a simple witness path matches its Manhattan lower bound. This equality proves that the displayed minimum is exact.
- Once every eye is covered, the eyes remain closed and the golden apple is placed only in the head's currently reachable free region.
- Death retries the same layout. Completing a level generates the next difficulty tier.

## Run

Open `v2.html` through a local web server.
